# ML Practice Week 1

## Project Description
This repository contains my Week 1 Machine Learning practice work, 
covering Simple/Multiple Linear Regression and Logistic Regression, 
built step-by-step as part of my ML Engineering learning journey.

## Dataset Used
- **California Housing dataset** (`sklearn.datasets.fetch_california_housing`) 
  for regression tasks
- **Titanic dataset** (`seaborn.load_dataset('titanic')`) 
  for classification tasks

## Steps Followed
1. Data loading and exploratory data analysis (EDA)
2. Missing value handling (median/mode imputation)
3. Categorical encoding (One-Hot, Label Encoding)
4. Feature scaling (StandardScaler)
5. Train-test split with stratification
6. Model training (Linear Regression / Logistic Regression)
7. Model evaluation using appropriate metrics
